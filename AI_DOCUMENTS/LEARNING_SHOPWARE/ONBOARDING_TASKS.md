## Advanced Topics & Plugin Development

Goal: Independent work on modules and initial backend functions.

Ideal learning goals:

- Development of your own sample plugin (e.g., discount logic, banner control, backend field)
- Introduction to error analysis and debugging (Shopware logs, Symfony Profiler, Xdebug)
- Use of the event system and dependency injection container
- Understanding the API architecture (Sales Channel API, Admin API)
- Own SQL database tables and fields
- Dealing with migrations, repositories, caching
- Introduction to integration tests
- Review and documentation of work results

These lessons should not take longer than a week. Keep the tasks manageable for someone onboarding to a *Junior* PHP / Shopware developer without much experience in Shopware or Symfony.
The task focus should touch important full-stack topics, but the development focus should be Shopware *frontend*.

So, don't be demoralised by the "Seven Days" concept. These lessons and exercises can easily keep you busy for 2 to 3 work weeks if you type (i.e. mistype and debug) by hand and do some reading to understand what you're learning.
