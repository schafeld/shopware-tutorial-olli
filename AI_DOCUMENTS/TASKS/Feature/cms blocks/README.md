# Reusable Shopware CMS Blocks

This folder contains feature requests and design documents for the creation of reusable Shopware CMS blocks.

## General Task

A specified HTML template file containing a UI widget (composed of HTML, CSS, and maybe Javascript) there needs to be reimplemented as a Shopware CMS block within this project. The reusable CMS Block needs to follow Shopware standards (using the proper file locations and names, integrate with Twig templates, transpose CSS to SCSS, etc.)

Every CMS Block needs to be documented in its extension/plugin folder.
Text and images found in the HTML widget template file should be made editable through Shopware.
Also documented should be how to install the CMS Block in Shopware and how to use it as an editor – the cms blocks may be used in Shopware Shopping Experiences and/or page templates.
